# Synthetic fixtures

Everything in this directory is **fictional**. No real custodian, planning
vendor, firm, account or person is represented. The files exist to exercise
the SageSpan (provisional brand) assurance workflow end to end without any
client data.

| Path | Purpose |
|---|---|
| `seed.json` | Demo state: two synthetic organisations, users, households, typed facts, open conflicts, imports and imported plan values. Loaded by the web app's demo store. |
| `sources/*.txt` | Synthetic "source documents" (custodian statements, profiles, beneficiary forms). Their SHA-256 hashes are recorded in `seed.json` and verified by tests. |
| `imports/*.json`, `imports/*.csv` | Supported `sagespan.import.v1` samples used both as seeded plan exports and as downloadable templates for the import screen. |
| `imports/unsupported_vendor_sample.csv` | A deliberately unsupported layout to demonstrate actionable rejection. |
| `calc/patel_rmd_request.json` | Exact request the web app sends to the calculation service for the reconciled Patel snapshot. |
| `calc/patel_rmd_expected_response.json` | Engine output for that request (generated by the Python engine; used by contract tests). |
| `scripts/compute_hashes.py` | Re-fills `sha256` / `byte_length` for source documents in `seed.json` from the files. |

## Households

* **Patel** (Harbor Point, synthetic): age-74 owner in 2026, traditional IRA,
  confirmed 2025-12-31 balance $640,000.00; planning-tool export carries
  $612,000.00 for the same date (material conflict, blocks freeze) and an
  imported 2026 RMD of $24,000.00. Expected independent RMD: $25,098.04.
* **Okafor**: date-of-birth conflict between custodian profile and plan export;
  spouse sole beneficiary more than 10 years younger, so the check is
  UNSUPPORTED (joint table not implemented) even after the conflict is resolved.
* **Reyes-Lindqvist**: plan export only; no custodian evidence, balance as of
  2025-09-30 rather than year-end. Freeze is blocked for missing evidence until
  the synthetic statement is imported.
* **Bauer** (Northline, synthetic, second tenant): clean facts, used for
  cross-tenant isolation tests.

Numbers for Okafor, Reyes-Lindqvist and Bauer are plainly synthetic and carry no
claim of independent validation.
